# js-web-scripts
A collection of JS scripts I've made for Tampermonkey to fix highly specific needs.

# IndieGala Store Price Filtering

A tiny little script that lets you filter out games from the IndieGala Store based on their price. Basically, it just hides them. It's meant to be used with prices in ARS, but a few small changes can be done to change or universalize the currency used.

# Metal-Archives MusicBrainz Integration

A script that adds a few buttons in Metal-Archives (Encyclopaedia Metallum) artist and album pages to allow for quick metadata importing into MusicBrainz.
